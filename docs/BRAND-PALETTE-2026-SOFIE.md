# OmniGaze Brand Color Palette 2026
## "Futuristic Intelligence" - Sofie's Version

**Created:** January 2026
**Author:** Sofie Levi
**Positioning:** Futuristic · Intelligent · Confident · Category Leader
**Industry:** Software / AI / Enterprise Tech

---

## Overview

This palette moves OmniGaze from "Warm Technical" (amber/purple) to "Futuristic Intelligence" (violet/indigo). The new direction signals enterprise authority, AI leadership, and premium positioning.

---

## 1. Core Brand Colors (Non-Negotiable)

These define OmniGaze's identity. Use consistently across all touchpoints.

### Midnight Intelligence (Primary Background)
```
#000034
```
- Main background
- Hero sections
- Dark mode default
- **Why:** Deep, serious, and premium without going "black startup"

### Omni Violet (Primary Brand Accent)
```
#7D67E1
```
- CTAs
- Active states
- Highlights
- Logos & icons
- **Why:** Signals innovation + trust + leadership

### Deep Magenta (Power Accent)
```
#8B1E5D
```
- Emphasis moments
- Data highlights
- Emotional punch
- Thought-leadership content
- **Why:** Authority + boldness color. Use sparingly but intentionally.

---

## 2. Supporting Futuristic Colors

These expand flexibility while staying on-brand.

### Electric Lilac
```
#816AE6
```
- Secondary buttons
- Hover states
- Graph accents

### Neural Indigo
```
#2B2F7F
```
- Card backgrounds
- Section separators
- UI depth layers

### Soft Plasma Pink
```
#BD909A
```
- Human warmth
- Founder content
- Brand storytelling
- **Why:** Keeps the brand from feeling cold or robotic
